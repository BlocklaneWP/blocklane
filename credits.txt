== Third-party code and assets ==

* enshrined/svg-sanitize by Daryll Doyle
  https://github.com/darylldoyle/svg-sanitizer
  Version 1.0.0 (2026-09-01), GPL-2.0-or-later. Bundled at
  inc/advanced/vendor/svg-sanitize/, with its license in
  inc/advanced/vendor/svg-sanitize/LICENSE. Sanitizes SVG uploads when the
  Settings screen's Safe SVG Uploads setting is switched on.

* Phosphor Icons
  https://phosphoricons.com
  MIT, with its license in inc/icon-collection/LICENSE. The Icon block's
  bundled starter set, inc/icon-collection/svg/.

* Phosphor Icons, in the carousel
  https://phosphoricons.com
  MIT, with its license in inc/carousel/LICENSE. The carousel arrow glyph
  catalog (inc/carousel/arrow-icons.json) and the carousel block icons.

* npm packages the build bundles
  The JavaScript and CSS the build writes into the plugin's build folders
  include some npm packages webpack bundles rather than loading from
  WordPress: WordPress packages WordPress itself does not load
  (@wordpress/dataviews, @wordpress/icons and the packages they use;
  GPL-2.0-or-later) and MIT and 0BSD packages such as Ariakit, Base UI,
  Floating UI, date-fns and clsx. Every build folder that ships a bundle
  carries a third-party notices file the build writes from what it bundled:
  each bundle, the packages in it, and each package's version and license
  text, for example inc/carousel/build/THIRD-PARTY-NOTICES.txt.

* @wordpress/icons path data
  https://github.com/WordPress/gutenberg/tree/trunk/packages/icons
  GPL-2.0-or-later, the same license as this plugin. The navigation menu
  button's five icons (menu, layout, category, grid, list) are that
  package's 17.0.0 glyphs, written as SVG in
  inc/extensions/loader/navigation-toggle/navigation-toggle.php.
